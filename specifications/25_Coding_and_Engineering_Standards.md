# 25_Coding_and_Engineering_Standards.md — Engineering Standards Specification

## 1. Purpose
This document specifies code style guidelines, naming conventions, docstrings, error handling standards, and Git commit formats across all languages (TypeScript, SQL, Python, Go).

---

## 2. Standard Guidelines
- **TypeScript**: ESLint + Prettier, strict mode enabled, explicit return types.
- **SQL**: Standardized lower snake_case table and column names, explicit foreign key constraints, capitalized SQL keywords.
- **Git Commit Convention**: Conventional Commits (`feat:`, `fix:`, `docs:`, `refactor:`, `test:`).
