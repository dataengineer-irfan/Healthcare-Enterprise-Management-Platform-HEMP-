# Service Authorization Module — Functional Requirements

## 1. Scope
The Service Authorization Module handles Prior Authorization (PA) intake (278 EDI), clinical necessity reviews, peer-to-peer consult cases, and medical necessity decision notifications.

## 2. Requirements
- **FR-AUTH-01**: Urgent and standard Prior Authorization request submission.
- **FR-AUTH-02**: Medical necessity review case assignment and SLA tracking.
- **FR-AUTH-03**: Auto-authorization scoring for pre-approved procedure codes.
