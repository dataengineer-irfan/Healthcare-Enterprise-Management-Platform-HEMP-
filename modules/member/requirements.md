# Member Module — Functional Requirements

## 1. Scope
The Member Module manages beneficiary eligibility, benefit plan coverages, demographic enrollment histories, and dependent relationships.

## 2. Requirements
- **FR-MBR-01**: Member enrollment processing via 834 EDI intake or direct portal registration.
- **FR-MBR-02**: Real-time 270/271 eligibility verification query engine.
- **FR-MBR-03**: Benefit copay/deductible accumulator tracking.
