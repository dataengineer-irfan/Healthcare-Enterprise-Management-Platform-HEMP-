# Frontend UI Applications & Components

This directory contains metadata-driven user interface components, applications, and design tokens.

## Architecture
- `components/`: Core metadata-rendered controls (`MetadataForm`, `EnterpriseGrid`, `WorkflowBar`).
- `apps/`: Web applications (Next.js / React) for Portal administration and healthcare workflows.
- `styles/`: Core CSS design tokens (themes, typography, HSL color palettes, animations).
